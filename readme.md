# 🎬 Netflix Customer Churn Analysis

##  Project Overview

This project analyzes customer churn behavior using a Netflix customer dataset. The objective is to identify the key factors influencing customer churn and provide actionable business insights through data analysis and interactive visualizations.

The project covers the complete data analytics workflow, including data cleaning, exploratory data analysis (EDA), SQL-based business analysis, and an interactive Tableau dashboard.

---

## Objectives

- Analyze customer churn patterns.
- Identify factors affecting customer retention.
- Compare churn across subscription plans, regions, devices, and demographics.
- Build an interactive dashboard for business decision-making.

---

## Dataset Features

The dataset contains customer information such as:

- Customer ID
- Age
- Gender
- Subscription Type
- Watch Hours
- Last Login Days
- Region
- Device
- Monthly Fee
- Churn Status
- Payment Method
- Number of Profiles
- Average Watch Time Per Day
- Favorite Genre

##  Project Workflow

### 1. Data Cleaning (Python)

- Imported dataset using Pandas
- Checked missing values
- Removed duplicates
- Corrected data types
- Performed data validation
- Saved cleaned dataset

---

### 2. Exploratory Data Analysis (EDA)

Performed analysis on:

- Customer demographics
- Subscription plans
- Device usage
- Watch hours
- Monthly fees
- Churn distribution
- Payment methods
- Favorite genres

---

### 3. SQL Analysis

Used SQL Server to perform business analysis, including:

- Customer count
- Churn rate calculation
- Subscription-wise churn
- Region-wise churn
- Device analysis
- Gender analysis
- Payment method analysis
- Customer engagement analysis

More than **20 SQL queries** were written to generate business insights.

- Identified customer segments with higher churn rates.
- Compared churn across different subscription plans.
- Analyzed customer behavior based on device preferences.
- Evaluated payment methods and regional customer distribution.
